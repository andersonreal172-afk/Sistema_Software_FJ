# Sistema_Software_FJ
Sistema de gestión de clientes, servicios y reservas desarrollado en Python para la Fase 4 del curso de Programación Desarrollar y planificar un trabajo colaborativo por medio de un repositorio en GitHub, donde desarrollaremos un sistema integral orientado a objetos para la empresa Software FJ que gestione clientes, servicios y reservas sin uso de bases de datos, aplicando principios de abstracción, herencia, polimorfismo, encapsulación, sobrecarga de métodos y manejo avanzado de excepciones, para garantizar una aplicación estable, modular, extensible y capaz de continuar funcionando ante errores.
